# 🎵 BakaMusic 插件订阅

为 BakaMusic 添加 Apple Music、网易云、QQ、酷狗、酷我、咪咕和 Bilibili 插件，搜索歌曲、导入歌单，享受多平台音乐体验。

**[打开订阅页面 →](https://music.cwo.cc.cd/)**

> 本项目整理与适配公开网络上的第三方接口，不提供或运营自有音源。使用前请阅读[法律声明与免责条款](#法律声明与免责条款)，尊重版权、支持正版。

## V1 与 V2 分发

本仓库保留最新 V1 公开插件实现与原路由；V2 从这些公开接口独立适配，不使用 LyraMesh 内部插件的 QQ 歌单、酷狗等接口。

| 版本 | 模板 | 订阅 | 插件 |
| --- | --- | --- | --- |
| V1 | `plugins/*.js` | `/api/subscription.json` | `/plugins/qq.js` |
| V2 | `plugins/v2/*.js` | `/api/v2/subscription`（也可用 `.json` 路由） | `/v2/plugins/qq`（也可用 `qq.js`） |

V2 七个平台 ID 为 `cc.baka.{am,wy,qq,kg,kw,mg,bilibili}`，酷我/咪咕版本为 **1.0.4**，网易云/酷狗为 **1.0.3**，QQ/Bilibili 为 **1.0.2**，Apple Music 为 **1.0.1**。本次按各平台公开 V1 基线恢复类型分派、排行榜分组、导入筛选与音质策略；酷我保留此前 HTTPS 修复。网易云/酷狗/酷我的歌词搜索保留原歌曲 ID 与完整业务元数据，不再返回旧版显示名 `platform` 身份别名，以兼容客户端严格身份校验。V1 保留原版本。客户端仅允许这套公开 V2 插件绑定 LX 解析器；内部 `lyra.mesh.*` 使用内部来源。

咪咕 V2 评论已改用官方 `user/comment/stack/v1.0` 接口，使用歌曲原生 ID；仅有版权 ID 的旧记录先查询歌曲身份。按最新评论 ID 续页，不重复合并热门预览。原网页评论路径现已跳转为网站 HTML，不能再作为评论 JSON 使用；服务错误及异常响应仍明确报错，不伪装成空评论。评论总数仅接受字符串或数字，超出请求页宽的响应明确报错。已安装插件需更新至 1.0.4。

本次修复 V2 歌单分类的分组与常用分类，按各自旧版公开插件分别保留分类和常用项顺序、ID 类型及筛选参数；已安装插件需在客户端更新后获得修复。客户端需支持扁平分类的分组字段，以及首页独立返回的常用分类 `pinned` 数组。

网页默认生成 V2 链接，可选择 V1。V2 导入依据响应内容，不依赖文件名、URL 后缀或 MIME；Key 和 source 不需要追加 `.json`。示例：`/api/v2/subscription?source=ikun&key=YOUR_KEY`。含 Key 的链接请勿公开分享。

V2 动态响应禁止共享缓存和内容变换，下载内容必须保留首行协议标记。Netlify 使用 `zisi` 打包器并包含运行时生成器，订阅和下载都走函数路由。

开发验证：`npm test`；设置 `BAKA_V2_PROBE` 为客户端 `v2_probe` 可执行文件路径后，测试会逐个检查全部音源生成的插件。`python tests/v2-native-distribution.py PATH_TO_BAKA_FFI SUBSCRIPTION_URL` 可通过真实客户端 Rust 下载、校验并恢复整份订阅。`BAKA_NETLIFY_BUNDLES` 指向已解压的官方 Netlify 函数包时，会额外验证脱离仓库的函数运行结果。

## 🚀 开始使用

1. 打开[订阅页面](https://music.cwo.cc.cd/)，选择音源。
2. 按页面提示填写 Key；免费音源无需填写。
3. 生成并复制订阅链接，在 BakaMusic 的插件管理中通过订阅导入。
4. 选择对应平台，搜索和播放音乐。

只使用某个平台时，也可以复制页面上的单插件链接导入。切换音源后，请用新链接重新导入对应插件。

## 🌊 选择音源

| 音源 | 是否需要 Key | 适用平台 |
|---|---|---|
| 全豆要 | 无需填写 | 网易云 / QQ / 酷狗 / 酷我 |
| 次合代 | 无需填写 | 网易云 / QQ / 酷狗 / 酷我 |
| 星海 | 无需填写 | 网易云 / QQ / 酷狗 / 酷我 |
| ikun | 需要对应音源的 Key | 网易云 / QQ / 酷狗 / 酷我 / Apple Music |
| 聆澜 | 需要对应音源的 Key | 网易云 / QQ / 酷狗 / 酷我 |
| OI | 需要当前会话的签名盐 | 网易云 / QQ / 酷狗 / 酷我 |
| 万象 | 需要万象卡密 | 由万象提供的独立聚合订阅 |

本站生成的音源订阅还包含咪咕和 Bilibili 两个免密插件，也可单独导入，无需音源 Key。万象订阅的内容以其最新订阅为准。

### 音质选择

以播放器中显示的可选音质为准。不同音源的可用档位可能不同，高音质无法播放时，可以尝试较低音质或更换音源。

- 全豆要、次合代的 QQ 提供 `128k`、`320k`、`flac`。
- 星海的酷我仅提供 `flac`，QQ 暂不开放 Hi-Res 和 `atmos_plus`。
- 聆澜的 QQ 支持 `master`。
- OI 的酷狗支持 `master`，不提供 `atmos_plus`；OI 各平台不提供 `flac24bit` 档位。

### OI 的 Key

填写当前会话中的 `_oi_salt`，格式为 **32 位小写十六进制字符**。GUID、`_oi_three_random` 和普通卡密不能替代签名盐；本站不会自动获取该值。

### 万象订阅

到[万象官网](https://api.vsaa.cn/user/login)注册并获取卡密，再在订阅页面选择「万象音源」，填写卡密生成链接。平台与插件版本由万象维护。

## ❓ 常见问题

### 导入提示 Key 错误

确认 Key 与所选音源一致，复制时没有多余空格。OI 需填写符合格式的 `_oi_salt`，万象需使用其官网提供的卡密。可回到订阅页面重新生成链接。

### 能搜索，但歌曲无法播放

先切换音质、换一首歌重试，再检查音源 Key 或平台登录是否有效；仍不可用时，可更换音源并重新导入对应插件。

### 更新后没有热搜、MV 或个人推荐

先在播放器中更新插件，再确认客户端支持对应功能。刷新订阅后，请检查已安装的插件版本是否与上方列表一致。

### 大歌单导入较慢

歌曲较多时需要等待分批加载，失败后可重试。歌单总数与当前已加载数量可能不同，列表可继续翻页加载。

### 酷狗歌单链接如何导入

在歌单导入中粘贴酷狗 APP 分享的完整链接（如 `https://m.kugou.com/songlist/gcid_.../`），带分享文案也可以；也支持输入纯数字酷狗码。

### Bilibili 私有收藏夹无法导入

在插件的「用户变量」中填写有效的完整 Cookie（`BILI_COOKIE`）。公开收藏夹无需登录；会员内容及部分画质仍需账号具有对应权限。

> 请妥善保管卡密、连接码和 Cookie，勿公开分享含凭据的订阅链接或插件文件。

## 🛠️ 自行部署

仅使用插件时，访问[在线订阅页面](https://music.cwo.cc.cd/)即可。

如需运行自己的订阅服务，准备 Node.js 18 或更高版本，在项目目录执行：

```bash
npm ci
npm start
```

打开 `http://localhost:3000`，无需构建。可通过 `PORT` 修改端口，通过 `BASE_URL` 设置订阅与更新链接使用的服务地址。

项目包含 Vercel 和 Netlify 配置，两者均提供上述 V1/V2 路由。Netlify 的 V2 订阅与插件下载必须重写到对应函数，并打包 `plugins/**` 和 `functions/**`；后者包含运行时读取的音源生成器。音源配置见 [functions/source-config.js](./functions/source-config.js)，Apple Music 客户端接入说明见 [集成文档](docs/APPLE_MUSIC.md)。
