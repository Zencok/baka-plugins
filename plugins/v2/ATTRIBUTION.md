# Public plugin attribution

Public V1 and V2 plugin metadata displays `BakaMusic` as the author.

The preserved public baseline at commit `20bfcc9` credits `Toskysun` for the
NetEase, QQ, Kugou, Kuwo, Migu and Bilibili plugins, and `BakaMusic` for Apple
Music. The independently adapted V2 providers retain this upstream provenance;
the display-author change does not replace any existing source or license notice.
